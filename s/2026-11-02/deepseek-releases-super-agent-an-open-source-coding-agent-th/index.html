DeepSeek releases Super-Agent, an open-source coding agent that doesn't wait to be asked

Always-on coding agents change how developer teams work, and they come from a lab with a very different cost base.

DeepSeek has released a prototype coding agent called Super-Agent as open-source code. Unlike chat-style assistants that answer when prompted, it watches developer group chats, spots coding problems and proposes fixes on its own. It is built on DeepSeek's agent harness, the scaffolding that gives a language model tools for longer tasks, and was made by the company's Harness team.

Digital Trends positions it against Anthropic's Claude Code and OpenAI's Codex. No benchmarks were published, and the article notes it is unclear how reliable the tool is on complex work or whether it is ready for large deployments. Digital Trends also cites a Bloomberg report that DeepSeek has raised about 100 billion yuan, roughly $15 billion, ahead of a planned IPO. That figure is a media report, not a company statement.

For product and frontend teams, the interesting shift is from agents you call to agents that listen and interrupt. That raises questions about permissions, noise and review that most teams have not yet settled. Because the code is open, it is also something to read and test before deciding whether to adopt it.
