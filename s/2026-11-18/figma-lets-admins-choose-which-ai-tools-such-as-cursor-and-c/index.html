Figma lets admins choose which AI tools, such as Cursor and Claude Code, can reach design files

Control over which agents can read design files is becoming a requirement for enterprise design teams.

Figma has added admin controls for third-party OAuth apps. Admins on Organization and Enterprise plans can approve specific apps, including MCP clients such as Cursor and Claude Code, and block the rest. A new Extensions tab in the admin console shows app requests and approved apps. The rollout runs over the coming days.

The change matters because coding agents increasingly read Figma files directly through MCP to generate front-end code. Until now, any connected tool could do that. In an interview on Wednesday, Figma's chief architect Kris Rasmussen described AI work as fast at first and then slow, because prototypes come quickly but checking and finishing them does not.

For design-system and front-end teams, it is worth agreeing with IT now which agents should have access to design files, before the new controls are switched on and block tools people already use.
