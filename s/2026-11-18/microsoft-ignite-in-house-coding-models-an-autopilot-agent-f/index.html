Microsoft Ignite: in-house coding models, an Autopilot agent for Microsoft 365 and shared Copilot Workspaces

Microsoft is building its own models and making agents into colleagues inside Teams, which changes how enterprise AI is bought and governed.

At its Ignite conference, Microsoft released MAI-Code-2 for everyday enterprise coding and MAI-Code-2-Flash for high-volume fixes. Both are available in GitHub Copilot. Microsoft's internal benchmarks claim MAI-Code-2 reaches 98% of OpenAI's GPT-6.1 Sol at 40% of the cost, though the cost figures use a 50% launch discount. New image, security and decision models were also announced.

Autopilot is a long-running personal agent that gets its own identity, memory and tool access inside a company's Microsoft 365 environment. Colleagues can @mention it in Teams. Copilot Workspaces, which replaces Notebooks, is a shared space where people and agents work on the same material. Both are rolling out through Microsoft's Frontier early-access programme. Copilot Code, which builds apps from prompts, becomes generally available in December.

For product teams, the pattern is that agents are treated as accounts with their own permissions. Microsoft's cheaper own models also put more price pressure on OpenAI and Anthropic inside its products.
