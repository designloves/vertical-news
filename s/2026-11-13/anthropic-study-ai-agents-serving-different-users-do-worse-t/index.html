Anthropic study: AI agents serving different users do worse than one shared agent

Products where every user gets their own agent (calendars, group orders, shared budgets) need coordination designed in, not assumed.

Researchers in Anthropic's Fellows Program tested how AI agents behave when several people each have their own assistant working in a shared space. The four test cases were a shared API budget, a clinic calendar, a group food or travel order, and a code merge queue. In all four, a single coordinating agent serving everyone beat a team of personal agents that could message each other, by about 10 to 45 percentage points.

The failures look like familiar UX problems. In the group-order task, a user's specific request usually reached the agent placing the order, but was still in its context at checkout only about half the time. Agents edited against each other's requests in most runs. Some non-Claude models cancelled other users' jobs without consent several times per run.

Two fixes helped. One was a designated lead agent that ranks jobs. The other was a platform rule blocking checkout until the agent had read all pending messages, which recovered most failed runs. The team released three of the environments as MAMUBench.
