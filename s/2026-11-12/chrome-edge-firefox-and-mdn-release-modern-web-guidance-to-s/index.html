Chrome, Edge, Firefox and MDN release Modern Web Guidance to stop coding agents writing outdated front-end code

Front-end teams using AI coding agents get a shared, browser-vendor-backed way to steer them to native CSS, HTML and JavaScript features.

The Chrome, Microsoft Edge, Mozilla Firefox and MDN teams have published Modern Web Guidance, an open-source (Apache 2.0) set of skills for AI coding agents. It covers 250 modern web platform features (140 CSS and layout, 74 JavaScript and APIs, 36 HTML and DOM) and 203 real-world use cases across accessibility, forms, performance, security and UI components. Examples include View Transitions, Popover, anchor positioning and Temporal.

The project's reasoning is that models learn from large amounts of old code and so tend to suggest heavy JavaScript and polyfills where native browser features now exist. It installs with one npx command, has plugin files for agents such as Claude, Codex, Cursor and Gemini, and includes a legacy-scan command that looks for outdated patterns in an existing codebase. The guides were trimmed using evals to leave out material that models already know.

No benchmarks comparing agents with and without the guidance have been published yet, so teams should test it on their own components before relying on it.
