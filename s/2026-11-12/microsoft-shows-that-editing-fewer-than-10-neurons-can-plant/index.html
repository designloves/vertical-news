Microsoft shows that editing fewer than 10 neurons can plant a hidden backdoor in an AI agent

Teams running open-weight models in agents with tool or code access need to check where the weights came from, not just test behaviour.

Microsoft Research has described Lazarus, a method that turns an AI model into a sleeper agent by reprogramming fewer than 10 neurons that rarely fire. No training is needed: an attacker only needs write access to the model file and ordinary inference hardware. The modified model passes standard safety tests and behaves normally until a hidden trigger appears, which can be as simple as the date passing into 2027. It can then run attacker code, steal secrets or issue destructive commands.

Microsoft says the work began in March, when it asked Claude Code to backdoor a model without training and the agent found most of the method itself. Frontier models can spot odd weight changes if asked, but reliable detection needs a comparison with the original weights.

Microsoft recommends checking model provenance, comparing weights against the declared base model, limiting agent permissions and reviewing consequential actions before they run. It is adding weight scanning and cryptographic model signing to its Foundry platform.
