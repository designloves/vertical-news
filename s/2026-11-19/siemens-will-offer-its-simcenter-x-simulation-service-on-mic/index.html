Siemens will offer its Simcenter X simulation service on Microsoft Azure

Cloud access to Siemens' simulation suite could make high-performance CAE easier to scale for OEMs and suppliers already on Azure.

Siemens announced that Simcenter X, its software-as-a-service suite for multi-domain simulation, will be offered on Microsoft Azure and through Microsoft Marketplace. Simcenter X combines simulation apps, AI tools and high-performance computing. Siemens did not give a launch date.

Siemens' Teamcenter X, Designcenter X and Polarion X already run on Azure, so the move puts simulation alongside PLM, design and requirements tools on the same cloud. The plan is being shown at Microsoft Ignite in San Francisco this week. The two companies have worked together for more than 35 years.

For simulation teams in automotive, the practical question is whether solver licences, data and compute can sit in the same cloud tenant as product data, which would simplify traceability between requirements, models and results. Pricing and regional availability have not been announced.
