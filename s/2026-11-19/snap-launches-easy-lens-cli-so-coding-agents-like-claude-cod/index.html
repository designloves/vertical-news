Snap launches Easy Lens CLI so coding agents like Claude Code and Cursor can build and publish AR Lenses

Platforms now design their creator tools for AI agents as well as for people, and the workflow is a model for other design tools.

Snap released a command-line version of its Easy Lens tool on Wednesday. Creators describe a Lens in plain language, and an AI coding assistant such as Claude Code, Cursor or Codex builds it. The agent creates assets, tests the Lens, fixes errors and sends new versions to the creator's phone for review. It runs on Mac, Windows and Linux.

Snap says the agent can use more than 100 AR building blocks and 50 AI asset generators, and can also publish Lenses and track how they perform. Snap claims a simple game can go from idea to published Lens in a day without the creator writing code. Lenses built this way can earn money through Lens+ Payouts, which Snap says paid creators $1.8 million last month.

For designers, the pattern is clear. The human sets the idea and judges the result on a real device, and the agent does the build. Expect more design and prototyping tools to offer agent-ready CLIs or APIs alongside their visual editors.
