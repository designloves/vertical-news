Google Labs launches Stitch Loop, an agent that keeps improving live products and opens pull requests for fixes

Design tools are moving from drawing screens to improving shipped products against real metrics, with accessibility built in.

Google Labs introduced Stitch Loop, an experimental, long-running product agent in its Stitch design family. It connects to a team's GitHub repository and to live product data such as logs, user behaviour and feedback, using more than 180 integrations, custom MCP servers and command-line uploads.

Each loop finds problems backed by evidence, proposes solutions with trade-offs and visual design options, builds the chosen fix in a cloud sandbox and opens a GitHub pull request with screenshots and video. It then watches live metrics to see whether the change worked. Three loops come by default: security (using Gemini 4 Carbon and DeepMind's CodeMender), latency and accessibility. Teams can add their own goals, such as checkout conversion. Nothing is merged without human review, and a Slack integration sends daily digests. There is a global waitlist, with AI Ultra subscribers first, and no pricing yet.

For designers, this moves AI from the mock-up stage into the live product. The accessibility loop is relevant to European teams now working under the European Accessibility Act.
