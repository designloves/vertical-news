Meta's Muse Spark Open is an 816B open-weight model that runs on two Mac Studios

a near-frontier model you can run locally is a real option for confidential OEM and product data.

Meta released weights for Muse Spark Open. It is a natively multimodal mixture-of-experts model with about 816B parameters, 42B active per token, and a one-million-token context. It is tuned for coding, long agentic tasks and multi-step reasoning. Meta's desktop example runs it on two M5 Ultra Mac Studios using MLX. It also works with vLLM, SGLang, llama.cpp and the other usual runtimes, on AMD, Apple, Intel and Nvidia hardware.

Weights are on Hugging Face and the major clouds. Groq, Together, Fireworks, OpenRouter and others host it. The license has "limited commercial terms", so check it before you build a product on it. Meta has not published benchmark numbers yet and says a full evaluation report is coming. Bloomberg notes that Meta's strongest models, the Muse Wonder series announced on 12 October, stay closed.

For Emil: this is a capable model for internal tools on engineering IP or unreleased product work, without sending data to a cloud API.
