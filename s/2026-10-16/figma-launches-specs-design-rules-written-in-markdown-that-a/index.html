Figma launches Specs: design rules written in Markdown that AI agents follow

design-system documentation now directly steers what Figma's agent and coding agents generate.

Figma used its first Config in India to announce Specs. A Spec is a Markdown document that can be its own file or sit on the canvas next to designs. It can embed frames, FigJam diagrams and code layers. Teams write their design language, rules and project context in it, and Figma's agent and outside coding agents use it as a reference. Agents connected through Figma's MCP server get a figma-spec skill to read and update Specs. Content can also be pulled in from GitHub or pushed out to Linear and GitHub.

Specs is in open beta on Professional, Organization and Enterprise plans, with a staggered rollout. Editing by hand is free. Agent actions use AI credits. Code layers, which put live code on the canvas for interactive prototypes, moved from private to public beta. The MCP server also gained more than 20 tool integrations.

For Emil: this is the same idea as a DESIGN.md for agents, but built into the canvas. Rules you write down once start showing up as more consistent AI output, for both designers and developers.
