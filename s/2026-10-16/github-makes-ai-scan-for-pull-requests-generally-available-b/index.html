GitHub makes AI Scan for pull requests generally available, billed with AI credits

a clear example of AI shown as labelled, non-blocking advice and charged by usage.

GitHub's AI Scan for pull requests is now generally available. It looks for vulnerabilities in code that CodeQL doesn't cover, such as PHP, shell scripts, Terraform, Dockerfiles, JSP and Blazor. Findings appear in the PR with an "AI" label that sets them apart from CodeQL results. They can include an explanation and a suggested fix, but they never fail checks or block merges. Agentic Autofix, which lets Copilot draft fixes for scanning alerts, also reached general availability.

It is free on public repos. Private repos need GitHub Code Security or Advanced Security. No Copilot licence is needed. Usage draws on Code Security AI credits, and admins can set budgets per SKU.

For Emil: there are two patterns worth copying. AI output is labelled and kept advisory rather than mixed in with deterministic results. Pricing moves from seats to metered credits with budget controls, the same issue the Accenture story shows from the buyer's side.
