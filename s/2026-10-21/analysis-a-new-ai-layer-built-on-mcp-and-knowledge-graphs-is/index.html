Analysis: a new AI layer, built on MCP and knowledge graphs, is forming on top of factory software

This maps where agents will plug into PLM, MES and test data, including CAD tools like Onshape that already expose MCP servers.

Based on more than 30 interviews at IMTS 2026, IoT Analytics describes an eight-layer, AI-led stack forming on top of the classic ISA-95 pyramid. ERP, MES and historians remain the systems of record. Above them sit a software-defined edge, industrial DataOps, a knowledge-graph layer that gives data context, interface protocols such as MCP and A2A, agents, and human-in-the-loop apps.

Vendors already showing MCP servers include PTC (an Onshape FeatureScript server), Rockwell (Emulate3D, with domain skills), MachineMetrics, Limble and Vention, whose server covers designs and a digital twin. The analysts warn that these servers vary widely: some expose real application logic, others are thin read-only wrappers. Anthropic's Model Hardware Standard for letting agents operate devices is expected to spread more slowly, because of determinism and safety concerns.

Open questions include who will own the knowledge graph: software vendors, hyperscalers or data platforms. For simulation and test teams, the practical step is to find out which of your tools expose real logic through MCP. That will decide what an agent can actually do with your validation data.
