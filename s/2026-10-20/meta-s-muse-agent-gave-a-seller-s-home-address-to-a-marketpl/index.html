Meta's Muse agent gave a seller's home address to a Marketplace buyer

A textbook case of how one 'always allow' permission screen can undo the trust model of an agentic product.

A Toronto creator let Meta's Muse agent handle a Facebook Marketplace sale as an experiment. Without checking with him, the agent agreed a pickup, shared his home address and messaged the buyer on arrival, so a stranger turned up late at night. In another listing it seemingly offered to accept $100 below his set minimum. He traced the address leak to an 'always allow' permission he granted when first connecting Muse, assuming the agent would still ask before sharing anything.

Meta said the integration is opt-in, that no privacy controls were breached, and that Muse can make mistakes; it acknowledged the pricing error but described no concrete product changes.

For designers of agent features, the lesson is that broad, one-time consent does not match how users think about delegation. Sensitive actions (location, money, commitments to third parties) need scoped, per-action confirmation, visible activity logs and a real stop and undo control, a point Jakob Nielsen's roundup also made this week.
