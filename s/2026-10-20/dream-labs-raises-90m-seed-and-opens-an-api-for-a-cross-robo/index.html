Dream Labs raises $90M seed and opens an API for a cross-robot foundation model

Robot control as a cloud API could make automating test-rig and lab handling tasks far cheaper.

Dream Labs, founded this year by former Nvidia researchers who worked on GR00T and world-action models, raised a $90M seed round led by B Capital and Kindred Ventures. Its Dream-1 model learns from videos of people doing everyday tasks and is meant to work across many robot types rather than one machine.

The Dream API takes a camera feed and a plain-language instruction and returns motor commands from the cloud; the company calls it the first public API for a robot foundation model. Customers can send a small set of demonstrations and get a fine-tuned model within hours. It supports gripper robots for tabletop tasks today through 20+ hardware partners, with arms costing about $2,000–$10,000; mobile bases and dexterous hands are planned.

For test and validation labs, cheap general-purpose manipulation could take over repetitive specimen handling or fixture loading, though cloud latency and safety certification remain open questions.
