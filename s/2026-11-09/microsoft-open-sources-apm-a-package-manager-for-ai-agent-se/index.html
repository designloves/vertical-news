Microsoft open-sources APM, a package manager for AI agent setups

Teams using several coding agents get a way to share and lock the same skills, prompts and tool servers across a project.

Microsoft has published APM, an MIT-licensed 'agent package manager'. A project lists the instructions, skills, prompts, agents, hooks and MCP servers it needs in a manifest file, and one command installs them. A lockfile pins the resolved versions, much like npm.

The repository says it works with Copilot, Claude Code, Cursor, Codex, Gemini and others, and can pull from several git hosts. Security features include scanning for hidden Unicode, integrity hashes, SBOM export and a consent step for transitive MCP servers. An organisation policy file can restrict allowed sources. The 7 November date comes from a daily digest, and we could not confirm a release date on the repository page.

For frontend and product teams this is a sign that agent configuration is being treated like any other dependency, with versioning and supply-chain checks. It is early, so expect the conventions to shift.
