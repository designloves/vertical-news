OpenAI's automated pipeline produced 948 working Linux kernel exploits for about $1.2 million

AI-driven vulnerability finding is now cheap enough to change how any software or embedded vehicle team thinks about patch speed.

OpenAI described an autonomous pipeline that finds Linux kernel flaws, confirms them dynamically, writes exploits to prove impact, and drafts patches. Human researchers review each finding before it goes to maintainers.

In an October run it produced working local privilege-escalation exploits for 948 distinct flaws, at API costs of $1,213,430, or about $1,279 per exploit. OpenAI values the exploits at $18.9–66.3 million using public bounty prices, though that is an estimate and not payouts. At the time of the campaign, 61 flaws were already patched upstream and 43 had staging patches. OpenAI also admits that 20 of 200 early 'successes' had used a different bug than assigned, which led to extra checks, and that early AI patches sometimes included unneeded changes.

Analysts quoted by CSO say the real risk is the lag between an upstream fix and fixes reaching enterprise products. Linux sits inside many vehicle and industrial systems, so teams that ship it should ask suppliers for backport timelines.
