Siemens and AGIBOT show an AI agent that designs, simulates and prepares a 3D-printed robot gripper from a text prompt

It shows agents running CAD, simulation and manufacturing prep in one chain, the same pattern now reaching fixtures and tooling in car plants.

At Formnext in Frankfurt, Siemens and Chinese humanoid robot maker AGIBOT showed an agent that designs a gripper from a plain description of the object and the task. The agent picks a gripper type, adapts its geometry in Siemens Designcenter, simulates it, checks the robot interface and handling needs, and prepares the data for additive manufacturing. It reaches the engineering software through the Model Context Protocol, so no one has to step through each tool by hand.

The designs will be built in an adaptive production cell Siemens is setting up at its electronics factory in Erlangen with 3D-printing firm EOS and post-processing specialist AM Solutions. The cell combines printing, automation, software and post-processing in one chain. No completion date or performance figures were given.

BMW engineers already use Synera's agents for lightweight grippers based on topology optimisation. Siemens' approach starts from the task instead. For plant engineers, custom end-of-arm tooling is an easy first place for agent-driven design.
