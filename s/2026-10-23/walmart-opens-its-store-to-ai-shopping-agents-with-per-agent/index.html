Walmart opens its store to AI shopping agents, with per-agent profiles and spending caps

This is a concrete template for agent permission UX: separate identities, approval rules and limits that users can see.

While Amazon blocks third-party shopping agents, Walmart is inviting them in. CEO John Furner announced Agent Gateway, an MCP server that lets approved AI agents search Walmart and Sam's Club inventory and buy on a customer's behalf. Agents never see payment details or purchase history, and they can only reach the data a task needs. Agents that break the rules are blocked. No Walmart+ membership is required.

Agent Profiles roll out in November. Each agent gets its own space inside the customer's account, so its orders appear separately. Customers can require approval for every purchase or set a spending limit, and they can delete an agent at any time. Walmart's normal returns policy applies even when an agent gets something wrong.

For UX designers, this is worth studying alongside Microsoft's agent-as-insider controls and the Meta Muse leak from earlier this week. Treat each agent as a named actor with a scoped role, visible activity and an easy kill switch, rather than as a hidden extension of the user's own session.
