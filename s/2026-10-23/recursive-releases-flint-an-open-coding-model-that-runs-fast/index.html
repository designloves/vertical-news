Recursive releases Flint, an open coding model that runs fast on a laptop

Strong local coding models make private, offline agent workflows realistic for frontend work and engineering scripts.

Recursive Superintelligence, the startup led by Richard Socher, released its first model, Flint, under the Apache 2.0 licence. It is a mixture-of-experts model with 39.8B total parameters, about 2.5B of them active per token, and a 262K-token context window. Quantised versions go down to about 11 GB, and Recursive reports around 125 tokens per second on an M4 Pro MacBook.

Self-reported scores include 89.7% on SWE-bench Pro v2, 74.2% on SWE-bench Verified and 54.9% on Terminal-Bench 2.1. These are vendor figures and have not been independently verified. Recursive says most of the development was automated by its own self-improvement system, which it calls the Eureka Machine.

If the numbers hold up, a frontend developer could run a capable coding agent fully on-device, and an engineer could do the same for Python post-processing of test data, without sending code to a cloud API.
