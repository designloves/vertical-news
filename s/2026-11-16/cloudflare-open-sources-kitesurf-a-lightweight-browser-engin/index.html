Cloudflare open-sources Kitesurf, a lightweight browser engine built for AI agents

More of a site's traffic will come from agent browsers that are not Chrome, and front-end teams will need to test for them.

Cloudflare has released Kitesurf under the Apache 2.0 licence. It is a browser engine that loads pages, runs JavaScript and renders them without Chromium or a browser container. It combines the Blitz layout engine and the Stylo CSS engine, runs scripts on Cloudflare's Dynamic Workers with the Boa engine as a fallback, and can output PDFs. It supports the Chrome DevTools Protocol, so tools like Puppeteer can connect, although not every feature works.

When Cloudflare first showed the engine in August, it reported three to seven times lower CPU and memory use than Chromium, for example about 58 MiB against 271 MiB per screenshot. Chromium still rendered about 1.7 times faster. Developers can run it locally, while hosting their own instance needs a paid Workers plan. Cloudflare calls it experimental.

For frontend developers, this adds another rendering engine that may visit their sites on behalf of users. Pages built on semantic HTML and standard layout are more likely to work in it.
