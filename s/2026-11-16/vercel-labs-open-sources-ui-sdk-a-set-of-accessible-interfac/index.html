Vercel Labs open-sources UI SDK, a set of accessible interface behaviours for coding agents

It addresses a common complaint about agent-written front ends, which is broken keyboard, focus and accessibility behaviour.

Vercel Labs has released UI SDK in public beta under the Apache 2.0 licence. It is a library of more than 50 'headless' behaviours with no styling of their own, such as popups, selection, typeahead, roving focus, reordering, drag-and-drop and virtualised lists. Adapters cover React, Vue, Svelte, Solid and Web Components. Focus handling, keyboard navigation and ARIA states are built in, and the core is described as aligned with WCAG 2.2 AA.

The release also includes an 'Agent Bridge' that lets AI agents operate an interface through MCP, using structured snapshots and actions instead of screenshots. Guardrails let developers allow or refuse agent actions on sensitive forms. Vercel says internal tests needed up to 69% fewer tool calls than DOM inspection, but that figure has not been checked independently. Stable React and Vue adapters are planned for early 2027.

For design-system teams, the idea is to give coding agents tested building blocks rather than letting them write interaction code from scratch. It also treats agents as a second kind of user that an interface has to serve.
