Stanford releases Memorilla, which squeezes a document collection into 16 memory tokens

Cheaper ways to give a model access to company documents could change how retrieval features in products are built.

Stanford researchers have open-sourced Memorilla, a memory module for large language models that are used unchanged, without fine-tuning. Instead of pasting long documents into the prompt or retrieving chunks, Memorilla compresses a whole document collection into 16 special memory tokens that the model reads alongside the question.

In tests with the frozen Qwen3-8B model, the team reports 84.33% accuracy on the FactKG fact-checking benchmark while using 108 times fewer document tokens than methods that load the full context. The code, training setup and evaluation benchmarks are released under an open-source licence.

The figures come from the authors and cover one benchmark and one model, so they need independent testing. If the approach holds up, it could cut the cost and delay of assistants that answer questions over manuals, specifications or test reports, which today often rely on large context windows or retrieval pipelines that are fragile to tune.
