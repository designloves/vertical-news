Cursor traces its poisoned Claude Code extension to a leaked key at Fireworks AI

A second AI product has now been hit through the same inference vendor, so teams need to audit what their model providers can reach.

Cursor has published the root cause of the incident in late October, when tampered versions of the Claude Code extension appeared in its marketplace. A key that Cursor had issued to Fireworks AI, the company that hosted some of its open-weight inference, was exposed. It gave read-only access to a shared storage bucket of coding-agent traces, mostly from 2025 sessions run outside Privacy Mode. Some of those traces contained credentials, which the attacker then used to get into Cursor's own services.

On 29 October a stolen credential let the attacker plant versions 2.1.312 and 2.1.313 of the extension in Cursor's marketplace cache for about 11 hours, reaching up to 5,000 users. The backdoor tried to add an SSH key, open a reverse tunnel and send out secrets from environment variables. Cursor says fewer than 0.05% of users had traces exposed, Privacy Mode prompts and customer code were not affected, and the last attacker activity was on 1 November.

Cursor has moved inference off Fireworks, revoked vendor access and rebuilt its marketplace. Notion reported a breach through the same provider earlier this week. The lesson for product teams is to keep secrets out of agent sessions and treat logged traces as sensitive data.
