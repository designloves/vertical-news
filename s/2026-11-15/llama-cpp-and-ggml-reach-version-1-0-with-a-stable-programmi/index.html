llama.cpp and ggml reach version 1.0 with a stable programming interface

The most widely used engine for running models locally now promises not to break apps between minor releases, which makes on-device AI easier to ship.

The open-source projects llama.cpp and ggml, which power much of the local and on-device AI ecosystem, released version 1.0.0 on Friday, about three and a half years after launch. Both now follow semantic versioning: any breaking change to the C programming interface or binary interface will require a new major version.

The 1.0 release removes deprecated functions, so apps that embed the library need to check for those when they upgrade. The engine supports more than 150 model architecture variants and the common speculative-decoding methods, and it builds for Linux, macOS, Windows, Android and iOS. It is packaged for Docker, Homebrew, Debian, conda-forge and Winget, and Nvidia, AMD, Qualcomm, Arm, IBM and Intel contribute hardware test machines.

For product teams, a stable interface lowers the maintenance cost of features that run models on laptops, phones or edge devices instead of in the cloud. That helps with privacy-sensitive features and offline use, and it makes local inference a more realistic option for desktop and mobile apps.
