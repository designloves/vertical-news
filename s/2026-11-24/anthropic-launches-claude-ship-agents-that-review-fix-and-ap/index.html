Anthropic launches Claude Ship, agents that review, fix and approve pull requests under a team-written policy

Frontend and product teams shipping with coding agents get a way to move human review from every change to the changes that matter.

Anthropic has introduced Claude Ship, a set of agents for the last stretch of software delivery on GitHub. Code Review, now generally available, checks pull requests against the codebase and posts sorted findings at Quick, Standard or Deep levels. PR Steward, in beta, fixes failing CI checks, merge conflicts and review comments, and explains after each push what it changed and how to undo it. It does not approve or merge.

The third part, Claude Approvals (beta), applies an approval policy that the team writes in plain language as a file in the repository. It can approve routine changes on its own or require a human sign-off, and it can run in observe-only mode first. A new /ship command in Claude Code pushes a change, opens the pull request and starts review. Billing is by tokens with admin spend limits, on Team and Enterprise plans.

Anthropic says merged pull requests on its own Claude Code team more than doubled between June and September while the share reverted fell by over 40%. For design-system and frontend teams, the practical question becomes which changes, such as tokens, copy or visual components, still need a person.
