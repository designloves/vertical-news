Anthropic describes a four-layer memory design for AI agents, including offline 'dreaming'

Product teams designing agent features get concrete evidence on what makes long-running AI memory work.

Anthropic's engineering team published a write-up on how agents keep memory between sessions. It describes four layers: searchable transcripts, memory notes, structured representations such as wikis, and a small block of context injected into every session. 'Dreaming' is an offline step that reviews transcripts and notes, fixes mistakes and promotes key facts upward.

The numbers are vendor-reported. On a database task, Opus 5.5's mean score rose from 0.655 to 0.838 with memory. In one test over about 350,000 files, a wiki built through repeated dreaming lifted wiki-only accuracy from 13% to 48%. Giving each contract its own page raised retained facts from 72% to 100%. A wiki that grew to 1.77 times the size of its source brought little benefit.

The practical lessons: keep the always-loaded layer small, let the model judge what is worth saving, and plan a maintenance pass so stale notes do not mislead the agent.
