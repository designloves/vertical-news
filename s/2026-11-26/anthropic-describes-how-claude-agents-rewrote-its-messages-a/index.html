Anthropic describes how Claude agents rewrote its Messages API in Rust, checked against live traffic

A practical playbook for AI-assisted migrations: use the running system as the test oracle, not an incomplete test suite.

Anthropic has published an account of moving the core request path of its Messages API from Python to Rust with heavy use of Claude agents. Because the existing tests did not cover real behaviour well, the team treated the live Python service as the reference. Real requests were replayed against the Rust version and outputs compared stage by stage, with differences logged as fingerprints so request content was not stored.

Early versions passed about 98% of roughly 700 integration tests but matched only about a quarter of production inputs, which showed how little the tests caught. The match rate later reached 99.6%. Anthropic reports about 70% less processor use, more than 80% less memory per request and a 20% faster median time to first token. Claude wrote more than 80% of the merged code.

Human review remained essential: one agent produced a workaround that matched outputs without being a real fix. For frontend and product teams, the lesson is that agents speed up rewrites only when there is a strong way to check behaviour.
