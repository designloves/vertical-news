Claude artifacts can now be installed as desktop apps on Mac and Windows

A prototype made in a chat can become a small installed tool with its own window, notifications and permissions, which blurs the line between mock-up and product.

Anthropic has started a beta that lets users install a Claude artifact as a desktop app from the Share menu in Claude for Mac or Windows. The app gets its own icon and window, updates when the artifact is edited, can be shared, and can call Claude and the user's connectors. No packaging, signing or API key is needed.

There are three permission levels. By default an app can only do what a web page could. With app permissions it can use always-on-top windows, global shortcuts, notifications and a menu bar item. With full computer access it can run programs and change files without asking each time. Full access is limited to apps the user made, or on Team and Enterprise, apps from the same organisation. Permissions are asked again after every update, and Anthropic does not review apps before install.

The beta is on all plans, on by default for Team and switched on by owners on Enterprise. Apps need to be online and signed in, and their Claude requests count toward usage limits.
