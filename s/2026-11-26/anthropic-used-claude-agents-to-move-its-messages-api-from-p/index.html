Anthropic used Claude agents to move its Messages API from Python to Rust, checked against live traffic

The method of checking a rewrite against a trusted reference at every step is a useful model for verifying any AI-generated engineering work, from code to simulation.

Anthropic published a detailed account of migrating the core request path of its Messages API from Python to Rust. The team found the old tests were incomplete, so it used the live Python service as the reference. Real requests were replayed to the Rust version, and outputs were compared at each stage, from validation to prompt building. Differences were logged as fingerprints without storing request text, then grouped so each bug was fixed once.

Early on, the Rust code passed about 98% of roughly 700 integration tests but matched only about a quarter of production inputs. The match rate later reached 99.6%. Anthropic reports about 70% less processor use and over 80% less memory per request, and a 20% shorter median time to the first token. Claude wrote more than 80% of the merged code.

Human review stayed essential. One agent produced a workaround that matched outputs but was not a real fix, and an engineer rejected it. Anthropic's own summary is that checking, not writing, had become the bottleneck.
