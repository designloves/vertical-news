Google gives Gemini control of the Mac, and Apple is reportedly building its own computer-use agent

Desktop apps are becoming something agents operate, so designers need to think about interfaces a machine can read and navigate as well as a person.

Google added computer use to the Gemini desktop app for macOS. Given an instruction, the agent fills in forms, repeats tasks across batches of files, sorts folders or builds slide decks from local files. It runs in a live preview inside the chat, so the user's own screen and cursor stay free. Users can pause or stop it and approve actions first. It is available in English in the US for Google AI Plus, Pro and Ultra subscribers.

On the same day, Bloomberg spotted an Apple job listing for a senior engineering manager to lead an AI agent that can use a computer: browse, work across apps, run commands and write and debug code. Bloomberg says Apple has considered launching as early as the end of next year, but the work is still at an early stage. Meanwhile macOS 27.3 will warn users before they give third-party agents full access.

For product teams, this means apps will increasingly be used by agents acting for a person. Clear labels, predictable flows and confirmation steps will matter for automation as much as they do for accessibility.
