OpenAI's 'Performance Factory' uses Codex agents to find and fix ChatGPT slowdowns

It is a detailed, real-world example of agents doing engineering operations, with honest numbers on accuracy and where humans still decide.

OpenAI described an internal system that runs Codex agents against performance regressions in ChatGPT. An alert opens a task. An agent searches metrics, logs, traces and code for the root cause, a separate adversarial Codex session challenges the diagnosis, and the agent then opens a pull request with a fix. After deployment, another agent checks whether performance is back to baseline.

In just over three months the system ran more than 1,700 investigations, about 17 a day, and found the root cause in over 600. In a manual review of 100 diagnoses, 70% were judged accurate and 30% needed more work. Engineers still write the workflows, review and merge every fix, and make the calls on architectural trade-offs. OpenAI says human review is now the bottleneck.

For product and engineering leaders, the useful parts are the structure: defined states, steps that require a human, a second agent acting as a critic, and checks after deployment. The same pattern could be applied to test triage or simulation post-processing.
