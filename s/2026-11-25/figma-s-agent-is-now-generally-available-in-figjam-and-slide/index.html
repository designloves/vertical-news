Figma's agent is now generally available in FigJam and Slides on all paid plans

The design tool's agent now covers the planning and presentation steps around design work, not just the canvas.

Figma has made its agent generally available in FigJam and Figma Slides on all paid plans, with connectors and file attachments supported in both. In FigJam it can pull context from tools such as Hex, Slack and Asana to build and fill boards and diagrams, and it can turn a messy board into an organised spec with a summary and next steps.

In Slides it can start a deck from an attached spec outline and a brand template, split crowded slides, sharpen key messages and draft speaker notes for a given audience. The release follows the agent's arrival in Dev Mode on 19 November, where it can inspect designs, compare versions and give code snippets.

For design teams, the agent now spans workshop, spec, handoff and stakeholder deck in one tool. The open question is how well it keeps decisions consistent as work moves between those stages.
