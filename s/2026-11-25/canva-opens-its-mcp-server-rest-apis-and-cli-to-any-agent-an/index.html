Canva opens its MCP server, REST APIs and CLI to any agent, and says agents typed 72% of its CLI commands in October

A major design platform is treating AI agents as a main way into the product, which changes how design tools are built, priced and discovered.

Canva has made its MCP server generally available with no waitlist, and added REST APIs, an expanded command-line tool, service accounts billed through the API, and access to its in-house Craft image model through both the API and MCP. Agents can now create editable designs, images and video, remove backgrounds, split flat images into layered files, and resize and export work.

Canva shared its own usage figures: nearly 500,000 sign-ups through MCP since October, MCP usage up 93% from September to October, and agents typing 72% of CLI commands in October. It says four in ten people arriving through MCP are new or lapsed users, and that expected recurring revenue from MCP has more than tripled since September, without giving a dollar figure. There are limits: each MCP user still signs in to their own account, service accounts cover only the REST API, and some tools such as resize and brand kits need a Pro plan or higher.

For product teams this is a live case of agents as an acquisition channel. It also puts pressure on Figma and Adobe, whose agent access is narrower.
