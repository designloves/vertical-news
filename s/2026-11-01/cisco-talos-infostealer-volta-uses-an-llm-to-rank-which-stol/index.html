Cisco Talos: infostealer VOLTA uses an LLM to rank which stolen accounts are worth most

Criminals are now using hosted AI models as analysts, which raises the bar for account security and API abuse controls.

Cisco Talos describes VOLTA, a self-deleting Windows infostealer first seen on 11 October. It takes browser passwords, cookies, cards, crypto wallet data, chat sessions, cloud and SSH keys, and uses stolen sessions to confirm details such as a home address. It then sends the bundle to a model through OpenRouter and asks for a ranked assessment of what the victim is worth.

The default model is Claude Opus 4.6. If the reply contains refusal phrases, the malware falls back to Kimi K2 and then Gemini 2.5 Flash, which Talos reads as the operator expecting refusals. All observed endpoints were third-party services. Talos advises blocking unexpected headless Chrome launches and revoking tokens after any infection.

For teams shipping AI products, the case shows why abuse monitoring and refusal behaviour matter. For everyone else, it shows that attackers are automating the triage step after a breach.
