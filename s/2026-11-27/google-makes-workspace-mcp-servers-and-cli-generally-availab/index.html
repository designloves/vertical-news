Google makes Workspace MCP servers and CLI generally available, and agents must use them from 1 February

Any product that lets an AI agent read or act on Gmail, Drive or Calendar data needs a migration plan, new OAuth settings and confirmation steps in its UX.

Google has made hosted MCP servers for Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks generally available, together with a Workspace command-line tool. From 1 February 2027, AI agents must connect through these instead of calling Workspace REST APIs directly. Regular apps can keep using the REST APIs.

Agents must identify themselves with OAuth clients marked as agentic, so admins can manage them like other apps. In the admin console, organisations can set human-in-the-loop rules and read agent audit logs. Routine actions such as drafting an email run without interruption. Admins can require users to confirm sensitive steps such as sharing data or reading external files. Existing data-loss rules apply to agents automatically.

Billing changes follow on 1 April 2027. A free Standard tier with published rate limits stays, and a paid Scaled tier charges for use above daily allowances. For product teams, this turns agent access into a governed and metered feature.
