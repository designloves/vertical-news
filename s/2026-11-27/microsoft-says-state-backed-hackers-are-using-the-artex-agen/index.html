Microsoft says state-backed hackers are using the ARTEX agent framework to automate attacks

Agent-driven attacks run at machine speed, so anyone shipping web apps, APIs or connected-vehicle back ends needs rate limits, secret hygiene and behaviour-based detection.

Microsoft published an analysis of ARTEX, an open-source AI penetration-testing framework released in July. It uses a set of LLM agents (a goal model, a planner, worker agents running tools in a real shell, and a reporter) and can plug in almost any model, including ones with safety guardrails removed. Microsoft has seen Chinese and North Korean state groups, among them Salt Typhoon and Onyx Sleet, as well as criminal gangs, using it.

ARTEX does not invent new attacks. It chains standard tools such as nmap, sqlmap and Metasploit with little human input. In one campaign Microsoft logged more than 151,000 failed sign-ins, peaking at 2,900 a minute. In one case an agent took five minutes to go from exposed GitHub credentials to data in Azure Key Vault.

Microsoft advises rate limiting, phishing-resistant MFA, removing secrets from code and automatic containment. It also suggests decoys and honeytokens that waste an agent's time and trigger alerts.
