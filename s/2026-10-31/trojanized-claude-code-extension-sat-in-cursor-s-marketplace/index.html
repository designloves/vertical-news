Trojanized Claude Code extension sat in Cursor's marketplace for about 12 hours

Developers' editors and extensions are a live supply-chain risk, and anyone who installed the tampered update needs to clean up, not just upgrade.

Attackers published a tampered update of the Claude Code extension on Cursor's marketplace on 29 October. Cursor says it was live from roughly 02:27 to 13:35 Pacific time and affected at most 5,000 users. Anthropic says its own systems were not compromised; the attacker used access to Cursor's marketplace. The Open VSX, VS Code Marketplace and npm channels show no sign of the bad version.

The malicious code ran before the legitimate extension. It added an attacker's SSH key to the user's authorized keys, tried to enable SSH, opened a reverse tunnel, installed persistence through a scheduled task, crontab or LaunchAgent, and sent host details and the names of sensitive-looking environment variables to the attacker's server. Versions 2.1.312 and 2.1.313 are affected; 2.1.314 is clean.

Updating is not enough. Affected users should isolate the machine, remove the SSH key and persistence entries, preserve evidence, and rotate credentials. How the attacker published under Anthropic's name is still unexplained. Teams should review which extensions their developers can install and what secrets sit in their environments.
