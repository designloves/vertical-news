Siemens shows an AI agent that designs, simulates and prepares a robot gripper for 3D printing from a prompt

It is a working example of an agent driving CAD, simulation and print preparation step by step, relevant to tooling and fixtures in vehicle plants.

Ahead of the Formnext trade fair in Frankfurt (17–20 November), Siemens presented 'gripper by prompt'. The user describes the object and the task, and an AI agent chooses a gripper type, adapts the geometry in Siemens Designcenter, simulates it, checks the robot interface and handling, and prepares the build data for additive manufacturing. The agent reaches the engineering software through the Model Context Protocol (MCP). The demonstration case is a gripper for an AGIBOT humanoid robot.

Siemens also plans an adaptive additive production cell at its electronics factory in Erlangen, built with EOS and AM Solutions, linking printing, automation, post-processing and software. No start date or capacity was given. Its consulting offering for finding additive use cases now also covers industrial AI.

For engineering teams, the notable part is the use of MCP to let an agent operate CAD and simulation tools in a sequence that engineers can check at each step. Grippers, jigs and fixtures are a sensible first target because they are low-risk and highly variable.
