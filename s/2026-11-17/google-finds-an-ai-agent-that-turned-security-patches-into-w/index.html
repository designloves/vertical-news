Google finds an AI agent that turned security patches into working exploits without human help

The time between a security patch and an attack is shrinking, so teams running web apps and connected products need faster patching.

In its latest AI threat tracker, Google Threat Intelligence Group describes a suspected Russian-speaking operator running a multi-agent framework called exploit_agent. It used several frontier and local models to compare popular web-application code before and after security updates, find the fixed vulnerabilities, write exploits and run them automatically. Google calls this a first, and a clear step up from what it saw in the previous quarter.

The framework was found on an exposed staging server that also held stolen data and scripts for reconnaissance, brute-forcing and webshells. Targets appear to include French media, entertainment and education sites. Google also lists other autonomous attack frameworks in circulation, including ARTEX, CAIRN, HexStrike AI and PentAGI, one of which was used against the aerospace sector. No victim counts were given.

For frontend and platform teams, the lesson is practical: once a patch is public, the window before automated exploitation may be hours rather than weeks. The same applies to the web portals and backends behind connected vehicles.
