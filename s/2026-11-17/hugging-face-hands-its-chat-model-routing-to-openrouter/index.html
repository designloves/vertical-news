Hugging Face hands its chat-model routing to OpenRouter

Model routing is becoming commodity infrastructure, so the cost of AI features increasingly depends on picking the cheapest model good enough for each task.

Chat-model requests on Hugging Face Inference Providers now run through OpenRouter. Each call is routed by live price, speed and reliability, and fails over to another provider within the same request if one goes down. Existing Hugging Face tokens and code keep working. Developers can add ':fastest' or ':cheapest' to a model name, name a provider directly, or switch providers off in settings.

At launch the service covers 160 models from 38 labs, including DeepSeek, Kimi, GLM, Qwen and OpenAI's open-weight gpt-oss. An optional beta writes request traces as JSON to the user's own Hugging Face storage. Image, video and audio models are not part of the change. OpenRouter did not disclose any Hugging Face markup.

For product managers, the move lowers the effort of trying open-weight models in prototypes and reduces lock-in to a single provider. It also makes it easier to compare price and latency across providers when budgeting AI features.
