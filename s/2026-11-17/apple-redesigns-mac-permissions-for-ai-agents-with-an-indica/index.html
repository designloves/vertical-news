Apple redesigns Mac permissions for AI agents, with an indicator when one app controls another

It sets a concrete consent pattern for agents on the desktop, and developers of agent apps will have to rework their onboarding.

Apple has announced new macOS security controls aimed at AI agents, arriving with macOS 27.3. The broad permission that let an app control the device and read data is being split into two settings, 'System & App Protection Override' and 'Accessibility'. Users grant access by picking the requesting app from a list, get prompts explaining what an app can reach, and can set apps to ask every time. A new on-screen indicator shows when one app is controlling another.

Apple is asking developers to redesign onboarding so agents request narrow access, scoped to specific folders or apps, instead of whole-system control. Backup and assistive apps can apply for special entitlements. The move follows privacy concerns around desktop agents, including a reported flaw in the ChatGPT Mac app. No rollout date was given.

For UX designers, this is a reference pattern for agent consent: ask per task, explain scope plainly and show clearly when software is acting on the user's behalf.
