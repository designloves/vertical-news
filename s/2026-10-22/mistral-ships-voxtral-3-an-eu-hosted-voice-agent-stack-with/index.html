Mistral ships Voxtral 3, an EU-hosted voice-agent stack with transcription from $0.0035 a minute

A European option for voice interfaces that can run on your own infrastructure, which matters for in-car and data-sensitive products.

Mistral released Voxtral 3. It includes Voxtral Small Transcribe 3 for speech-to-text in more than 50 languages, and Voxtral Mini TTS 3 for text-to-speech in over 35 languages and 50 dialects, with emotional adaptation. Transcription starts at $0.0035 per minute.

A voice-agent SDK built on LiveKit handles listening, reasoning, tool calls and speech in a single streaming pipeline, so an agent can, for example, look up an invoice or book an appointment mid-call. It is available through Mistral's EU-hosted API or on the customer's own infrastructure. Licensing and latency figures were not detailed in coverage.

The same day, ElevenLabs launched Eleven Realtime speech-to-speech models. Voice is quickly becoming a commodity layer, so differentiation moves to turn-taking, error recovery and handing off to visual UI.
