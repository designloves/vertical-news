Perplexity's Computer agent can now run fully on-device on Apple silicon Macs

Local-first agents change the privacy and permission UX: files stay on the machine unless the user explicitly approves cloud access.

Perplexity added a local-first mode to its Mac app. Both the model and the agent that directs tasks run on the device, even offline. Users download local models (Qwen 3.6 and Perplexity's own PPLX Pro), and Perplexity recommends at least 36GB of unified memory. With permission, the agent can work with local files and apps such as Notes, Mail, Messages and Numbers.

Cloud access becomes an explicit opt-in per task, for fresh web information, browser use or connected apps, and the existing Hybrid Compute mode is still available in the same app. It is included for Pro, Max and Enterprise subscribers.

For designers, this is a useful pattern to note: a visible boundary between local and cloud work, with escalation only when the user approves. It could matter for European and regulated users, where data residency is often the main objection to agent tools.
