Figma adds native 3D transforms that work with its agent, Motion and code handoff

One of designers' longest-standing Figma requests now flows through to animation and production code in a single workflow.

Figma has shipped native 3D transforms. Designers can rotate layers on the x, y and z axes using handles on the canvas with live previews, and adjust perspective and depth to build simple 3D scenes. Scenes can be built by hand or assembled by the Figma agent, which became generally available in October and runs on AI credits.

The feature works with Figma Motion, now in open beta with Lottie export, so designers can animate flips, turns and perspective shifts. For handoff, developers can copy the CSS from Dev Mode or send the design to a coding agent through Figma's MCP server. Figma has also published a community playground file for trying the feature. Plan and pricing details were not given in the coverage.

For product and frontend teams, the notable part is the chain from canvas to motion to code. Since browsers already support CSS 3D transforms, designs made this way should translate more directly into production than mock-ups made in separate 3D tools. This summary relies on secondary coverage of Figma's release note.
