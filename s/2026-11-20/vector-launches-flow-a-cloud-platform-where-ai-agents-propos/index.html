Vector launches FLOW, a cloud platform where AI agents propose changes and prepare compliance evidence for vehicle software

A major tool supplier is building agents into the software-defined vehicle V-cycle, from specification to fleet data.

Vector Informatik premiered Vector FLOW at its NEXT HORIZONS conference in Stuttgart. The cloud platform links specification, development, validation, deployment and fleet operation, and feeds field data back into engineering. Vector calls this the "Big Loop".

FLOW includes predefined workflows, quality gates and AI agents. The agents can propose system changes, adjust tests and prepare evidence for regulatory compliance. Every workflow passes the same quality gates, so the required evidence is produced as part of the process. Vector's Marcus Eggenberger summed it up as "Humans specify, design and validate; agents take care of the rest." A fleet management module for monitoring and updating mixed device fleets is available now. The platform is open and modular, so existing customer and partner tools can be plugged in.

For teams working on testing and type approval, the claim to watch is automated compliance evidence. If it holds up, it could cut the paperwork around software updates under UN R155 and R156. Vector named no customers.
