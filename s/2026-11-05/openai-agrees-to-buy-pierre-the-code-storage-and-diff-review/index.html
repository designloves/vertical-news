OpenAI agrees to buy Pierre, the code-storage and diff-review startup behind parts of Codex

Another sign that AI labs are buying developer-tool infrastructure to own the whole coding workflow.

OpenAI said on 4 November it will acquire Pierre Computer Company. Pierre makes Code Storage, a Git-based service for apps that store code and its history, plus the open-source libraries Trees (file navigation) and Diffs (reviewing large code changes). Trees and Diffs already run inside the Codex app.

The price was not disclosed and the deal is subject to customary closing conditions, including regulatory approvals. Until closing the companies stay separate. OpenAI says the open-source projects will remain open and that Code Storage customers can keep using it after closing while it brings those features into Codex, without giving an end date for the standalone service.

For teams building on Pierre's tools, the open question is the long-term future of the standalone product.
